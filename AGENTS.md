# MPTinnitus Codex Instructions

This is a native iOS 17+ SwiftUI MVP for an educational tinnitus management app.

Locked rules:
- Do not add networking.
- Do not add accounts or login.
- Do not add cloud sync.
- Do not add analytics.
- Do not add Firebase, Supabase, CloudKit, or backend services.
- Do not add clinician dashboards or remote monitoring.
- Do not transmit user data.
- Do not add third-party packages unless explicitly requested.
- Keep all user data local-only.
- Build with SwiftUI, SwiftData, and AVFoundation only when the current stage requires them.
- Follow the current staged handoff prompt.
- Do not implement future stages early.

For Stage 01:
Only implement the app shell, folder structure, four bottom navigation destinations, placeholder screens, and placeholder audio mini-player.
