# Stage 07: Core Exercise Components

## Objective

Implement the MVP exercises and local entry workflows.

## Input files

01_SOURCE_OF_TRUTH/02_mvp_screen_spec_pack.xlsx, 01_SOURCE_OF_TRUTH/08_local_data_schema.xlsx

## Prompt to Codex

You are building the MPTinnitus iOS MVP. Follow the locked app contracts. Do not add networking, accounts, cloud sync, analytics, remote monitoring, clinician dashboards, or features outside the MVP unless explicitly requested.

Implement exercise components in groups: Body/Mind/Life, Sound Therapy Sweet Spot, Sound Preference, Sound Plan, Sound Sensitivity Music Exercise, Tug-of-War, Yes AND, Reconnection with What Matters, Deep Breath Check-In, 3-2-1 Senses, Mindful Listening, Sound Shifting, STOP, TIPP, Ice Cube Reset, Frozen Orange, Distortion Detective, Evidence For-and-Against, Balanced Reframe, Re-Scripting Self-Critical Thought, DEAR MAN, Sleep Thought Reframing, Bedtime Sound Plan, Three Lines Journal.

Each exercise supports Save, Skip, Repeat, View/Delete past entries where applicable, and Add to My Plan where applicable.

## Acceptance criteria

Each core exercise has a functional screen, saves local entries, and can optionally add a useful result to My Plan. Exercises do not require completion tracking or scoring.

## Expected output

Interactive exercise components and local save flows.
