# Stage 09: Mindfulness Annex and Guided Practices

## Objective

Implement the dedicated mindfulness practice area.

## Input files

01_SOURCE_OF_TRUTH/02_mvp_screen_spec_pack.xlsx, 01_SOURCE_OF_TRUTH/07_visual_interaction_manifest.xlsx

## Prompt to Codex

You are building the MPTinnitus iOS MVP. Follow the locked app contracts. Do not add networking, accounts, cloud sync, analytics, remote monitoring, clinician dashboards, or features outside the MVP unless explicitly requested.

Build the Mindfulness Annex with quick access to Deep Breath Check-In, 3-2-1 Senses, Mindful Listening, Sound Shifting, and future longer practice placeholders. Add a lightweight breathing pacer with inhale/hold/exhale labels and count highlighting. Longer recordings can be dropped in later.

Muse is not integrated in MVP. If mentioned, it is education/future resource only and not a device integration.

## Acceptance criteria

Users can open Mindfulness Annex, launch practices, play guided audio, see transcripts, and use a simple breathing pacer. No Muse integration exists in MVP.

## Expected output

Mindfulness Annex and simple breathing pacer.

## Review before moving on

- Does the app compile?
- Did this stage avoid adding disallowed services or MVP-expanding features?
- Are placeholders named clearly?
- Are source-of-truth IDs preserved where relevant?
